# GABS v1.1.1 release notes

GABS 1.1.1 makes corrupt GABP streams fail immediately with an actionable
disconnect reason.

- Malformed `Content-Length` framing is reported as a corrupt GABP frame and
  the connection is closed.
- A complete frame containing invalid JSON now closes the connection
  immediately instead of leaving requests to time out before a later framing
  error exposes the broken stream.
- An ordinary request timeout remains local to that request and does not close
  an otherwise usable GABP connection.

There are no configuration or protocol-version changes. Game-side bridges
must still serialize complete outbound frames when events and responses can be
written concurrently.
